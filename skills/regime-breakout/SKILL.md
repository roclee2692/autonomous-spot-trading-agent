# Breakout

Read [the Constitution](../../references/trading-constitution.md) and [market structure](../../references/crypto-market-structure.md). Use price versus prior range, volume, and MA slope as primary evidence. Funding, OI, liquidations, and ETF flow are context only.

Cancel or pause Range Grid proposals. If price returns to the prior range, request RANGE reevaluation; if follow-through persists, request trend reevaluation. V1 has no breakout execution planner, so do not invent orders.
